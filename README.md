🎯 Number Guessing Game

📌 About the Project

The Number Guessing Game is a simple Python project where the computer generates a random number and the player tries to guess it.

The player can select a difficulty level and gets a maximum of 10 attempts to find the correct number.

🎮 Difficulty Levels

- Easy: Number between 1 and 50
- Medium: Number between 1 and 100
- Hard: Number between 1 and 1000

Each level gives the player 10 attempts.

⚙️ How It Works

1. The player selects a difficulty level.
2. The program generates a random number.
3. The player enters a guess.
4. The program gives a hint:
   - ⬇️ Too Low – Guess a higher number.
   - ⬆️ Too High – Guess a lower number.
5. If the player guesses correctly, the game displays a success message.
6. If all attempts are used, the game ends and shows the correct number.

🛠️ Technologies Used

- Python
- Random module

▶️ How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code and run:

python number_guessing_game.py
